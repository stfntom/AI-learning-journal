## 1. LLM 和 Agent 最核心的区别是什么？

LLM像是只嘴，它只能在经过思考后只能给你信息的反馈，不能帮你完成你想做到具体事情
Agent像私人助手，它能自己规划任务计划，执行计划，再检验自己的交付结果，提高我的工作效率，减少我的工作量。

---

## 2. Agent 有哪三个核心组件？

1.规划能力
2.工具调用
3.记忆与反馈

---

## 3. 播客说评价 Agent 应该看什么？不应该看什么？

应该看：交付结果的能力和效果
不应该看：使用的是什么模型

---

## 4. Genspark 和 Flowith Neo 的主要差异是什么？

Genspark：在多种场景下，交付能力稳定，交付结果也比较优秀
Flowith Neo：分析细致但耗时较长，慢工出细活
差异一句话：Genspark综合能力更突出，Flowith Neo 有耗时的缺点，但能力强

---

## 5. 横评的重点不是比谁赢，而是什么？

而是比较在相同场景下不同的Agent处理问题的水平，通过对比不同表现，我能从多个角度加深对概念的理解
