## 【学习材料】先看这里，再看问题

### 今天我们实际做了什么？

1. 在 Coze 用 AI 创建了一个「学习助手」智能体，它自动生成了一套 Prompt（藏在 `config/agent_llm_config.json` 的 `"sp"` 字段里）
2. 用一段测试笔记测了它的效果 → 输出还行，但不够结构化
3. 把 Prompt 从「一句话描述」改成了「角色+任务+格式+约束」四件套 → 输出明显更规整
4. 把同一套升级版 Prompt 发给 DeepSeek → 输出更生动，类比更多

### 核心概念：什么是 Prompt Engineering？

> Prompt Engineering = 用结构化指令让 AI 稳定输出你想要的结果，而不是让 AI 猜你想要什么。

**生活类比**：你让朋友帮你买咖啡。
- ❌ 普通 Prompt：「帮我买杯咖啡」→ 朋友会追问：什么口味？冰的热的？大杯中杯？
- ✅ 升级 Prompt：「帮我买一杯中杯冰美式，不加糖，去公司楼下星巴克买」→ 朋友拿了就走

AI 也是一样：你说得越清楚，它越不需要追问。

### 升级版 Prompt 的四要素（今天实物验证过的）

| 要素     | 作用               | 今天升级版里对应什么                             |
| ------ | ---------------- | -------------------------------------- |
| ① 角色定义 | 让 AI 知道它是谁、用什么语气 | "你是一位专为零基础 AI 学习者服务的学习助手，语气像耐心的学长/学姐" |
| ② 任务目标 | 具体要做什么，分几步       | "提炼核心概念 → 生成3道自检题 → 给出下一步学习建议"         |
| ③ 输出格式 | 规定模板，防止 AI 自由发挥  | "必须按 ## 🧩/## ✅/## 🚀 三段输出"            |
| ④ 约束条件 | 明确告诉 AI 什么不能做    | "禁止编造用户笔记中没有的知识、禁止用专业术语不加解释"           |

### Coze vs DeepSeek 实测对比

同一个升级版 Prompt，同样的测试笔记，结果不同：

| 对比维度   | Coze（豆包-lite） | DeepSeek    |
| ------ | ------------- | ----------- |
| 核心概念数量 | 3个            | 5个          |
| 解释风格   | 简洁、偏定义式       | 详细、带生活化类比   |
| 自检题格式  | 混合（选择+判断）     | 全部4选项选择题 ✅  |
| 建议可操作性 | 3条建议，较宽泛      | 3条建议，更具体可操作 |

**关键发现**：Prompt 决定了输出的「骨架」（结构、格式），但底层的 AI 模型决定了「血肉」（表达力、丰富度）。同样一套 Prompt 在不同平台效果不同，因为模型能力不一样。

### 为什么升级后输出更稳定？

因为没升级时，AI 只知道"你的身份是学习助手"（一句话），它要自己猜测输出格式。升级后你直接告诉它输出模板，它不需要猜了。

**类比**：考试时，开放式作文（"写一篇读后感"）vs 结构化作文（"写读后感，必须包含：①一句话概括 ②三个感悟 ③一个行动计划"）——后者的答案一定更统一。

## 一、基础版 Prompt 的问题

1. **范围太简略**：只有一句话描述，AI 不知道具体要做什么
2. **具体框架要 AI 自己猜**：没有给输出模板，AI 每次可能输出不同结构
3. **增加多轮对话**：因为不够清楚，需要反复追问才能得到想要的结果

## 二、升级版 Prompt 的四要素

| 要素     | 我的理解（一句话） |
| ------ | --------- |
| ① 角色定义 | 让 AI 知道自己是谁、用什么语气说话 |
| ② 任务目标 | **最重要**——这是核心内容，决定 AI 到底要做什么 |
| ③ 输出格式 | **其次重要**——让思路更有逻辑性，输出更直观 |
| ④ 约束条件 | 划定边界，告诉 AI 什么不能做 |

## 四、我的理解

### Q1：为什么升级后输出更稳定？

> 因为升级后直接告诉了 AI 输出模板，它不需要自己猜框架了。就像考试时给了答题格式要求，大家的答案自然更统一。

### Q2：为什么同一套 Prompt 在不同平台效果不同？

> 因为两个平台用的 AI 模型不同。Prompt 是指令，模型是执行指令的人，不同人理解能力和表达风格不一样。

### Q3：Coze 和 DeepSeek 各自适合什么场景？

> - Coze 适合长期、有规范的场景——Prompt 固化成智能体后可以反复用，不用每次重新写
> - DeepSeek 适合理解需求的场景——模型能力强，适合临时提问、深度对话
