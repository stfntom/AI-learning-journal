## 第二部分：自己横评（已完成）

### 测试 prompt

```
请帮我解释以下 2 个概念，每个概念用：① 一句话定义 ② 一个生活化的比喻。

概念列表：
1. Agent（智能体）
2. LLM（大语言模型）

输出格式：每个概念单独一段，段内用 ①② 标注。
```

### 对比结果

| 维度 | DeepSeek | Kimi | 通义千问 |
|------|----------|------|----------|
| **Agent 的一句话定义** | 能自主感知环境、制定计划并调用工具执行复杂目标任务的智能系统，不只"思考"，更会"行动" | 能感知环境、自主决策并执行动作以实现特定目标的智能系统，能主动调用工具、规划步骤并完成复杂任务 | 能自主感知环境、进行决策并采取行动以达成特定目标的智能系统 |
| **Agent 的比喻** | 拥有秘书、计算器和百科全书的全能私人助理——说"策划一次旅行"，就查天气、订机票、写行程表、根据反馈调整 | 全能管家——说"筹备生日派对"，就联系场地、采购蛋糕、发送邀请，全程无需逐项指挥 | 全能私人助理——说"规划三亚旅行"，就查机票、比酒店、做攻略并完成支付 |
| **LLM 的一句话定义** | 基于海量文本训练出的深度神经网络，根据上下文预测并生成最有可能接续的自然语言文本 | 通过海量文本数据训练出来的深度学习模型，核心能力是"读得多、说得像"，不主动执行外部操作 | 通过海量文本数据训练而成，具备强大语言理解、生成与推理能力的人工智能基础模型 |
| **LLM 的比喻** | 被灌输整个图书馆书籍的"超级接话大师"——你说上半句，它接下半句，但不真正理解内容 | 博览群书的学者——能引经据典，但没法真的端起咖啡送到隔壁桌 | 博览群书、过目不忘的超级大脑——能写文章、翻译、聊天，但不会主动操作手机或电脑 |

### 我的结论

- **解释 Agent 我觉得最好的是**：Kimi
  - 因为它让我明白了：用"全能管家"比喻很具体，"筹备生日派对"的例子让我一下子知道 Agent 是要主动做一连串事，不只是回答。
- **解释 LLM 我觉得最好的是**：Kimi
  - 因为它让我明白了："学者能告诉你怎么送咖啡，但不能真的端过去"这个比喻非常直接，让我马上懂 LLM 为什么"只能说不做"。
- **横评让我新理解了什么**：
  - 同一个 prompt，三个模型说的内容其实大同小异，但比喻不同，让我从三个角度理解了 Agent 和 LLM 的区别。
  - 通义千问主动问我"要不要梳理两者关系"，这个追问行为本身就是 Agent 特征的一个例子——它不只是回答，还在想"下一步还能帮你做什么"。

## 综合感受

- **哪个模型让我意外？**：通义千问。它会主动追加"要不要梳理关系"，这个问题本身让我意识到 Agent 和 LLM 是"大脑+手脚"的关系。
- **横评过程让我发现了什么？**：比喻质量比定义更重要。DeepSeek 的定义最完整，但 Kimi 的比喻让我真正懂了。
- **我以后的主力模型还是**：DeepSeek（日常主力不变），但解释复杂概念时会考虑用 Kimi 再跑一遍。
