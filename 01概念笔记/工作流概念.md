# 工作流（Workflow）概念

> Day6学习 | 2026-07-31 | 检测通过（3道题全对）

## 一句话理解

**工作流 = 把复杂任务拆成多个固定步骤，每步有明确输入输出，像流水线一样逐步完成。**

## 三者核心对比

| 维度 | 单条Prompt | 工作流 | Agent |
|------|-----------|--------|-------|
| 谁设计流程 | 无流程 | **人**提前设计 | **AI**自己决定 |
| 灵活性 | 低 | 低（流程固定） | 高（自主判断） |
| 可控性 | 中 | **高**（每步可检查） | 低（可能跑偏） |
| 适合什么 | 简单任务 | 步骤明确、需稳定输出 | 开放性、需探索的任务 |

## 最关键的区别：工作流 vs Agent

- **工作流**：人设计路线，AI走路线。路线固定，结果稳定。
- **Agent**：给AI目标，AI自己找路线。灵活但可能跑偏。
- 一句话：**工作流是"你按我说的步骤做"，Agent是"你自己想办法做到"**

## 在Coze中的体现

- Agent = 对话型智能体（用户聊天 → AI自主响应）
- 工作流 = 节点型（多节点串联执行）
- Agent可以**调用工作流**来处理复杂子任务

## 生活类比

| 方式 | 类比 |
|------|------|
| 单条Prompt | 让一个人从头到尾一口气做完一道菜 |
| 工作流 | 流水线：洗菜→切菜→炒菜→装盘，每步专人负责 |
| Agent | 让一个厨师自己看着办，他决定先做什么后做什么 |
