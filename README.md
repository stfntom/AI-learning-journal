## 方法论沉淀

- **token 验证法**：判断知识库是否真的接进模型——看运行日志的 prompt_tokens（纯 Prompt 时 ≈ 系统提示词长度；带上检索会大幅上涨）
- **硬证据优先**：界面提示（如"上下文未启用"警告）不作为结论，以可测量的数据为准
- **多 AI 交叉验证**：生成 → 检查 → 自己整合（适用于概念/方案；不适用于最新界面与实时数据）
- **识别确认流程**：截图 → 只看清的说清 → 确认 → 再操作（避免瞎猜界面）
- **断档重启协议**：断 1–2 天直接继续；3–7 天 1 道快检+新任务；>7 天走"归位日"（核查事实→给选项→当天产出小成果），不补账
- **每日底线任务**：答 1 题 / 写 3 行 / 存 1 张截图（三选一）
