3. **注册 Coze（扣子）账号** ⬜

   - 用手机号或抖音账号登录
   - 截图：`day5-Coze注册页面.jpg`

4. **创建第一个简单 Agent** ⬜
   - 打开 Coze，点"创建 Bot"
   - 给 Bot 取名（比如"学习助手"）
   - 选一个简单场景：帮你总结每日笔记
   - 填写 Bot 的角色设定、能力描述
   - 添加一个技能（比如"文本总结"）
   - 发布并测试对话
   - 截图至少 2 张：
     - `day5-Coze创建界面.jpg`（创建过程中的界面）
     - `day5-Coze对话测试.jpg`（和你的 Agent 对话测试）

5. **用升级后的 Prompt 测试同一个 Agent** ⬜
   - Prompt Engineering 升级公式：
     > 角色设定 + 任务拆解 + 输出格式约束
   - 原版 prompt：`帮我总结今天的学习笔记`
   - 升级版 prompt：
     ```
     你是一位AI学习助手，专门帮助零基础学习者梳理每日学习成果。
     
     请帮我总结今天的笔记，按以下格式输出：
     1. 核心概念（一句话概括今天学到的最重要的概念）
     2. 关键收获（3条，每条一句话）
     3. 待解决问题（列出1-2个还没搞懂的问题）
     4. 明天计划（1句话）
     
     输出要求：语言简洁，不用专业术语，让我一看就懂。
     ```
   - 对比原版和升级版的效果差异
   - 截图：`day5-Prompt升级对比.jpg`

6. **在 DeepSeek 上测试同一个升级 Prompt** ⬜
   - 把上面的升级版 prompt 发给 DeepSeek
   - 对比 Coze Agent 和 DeepSeek 的回答差异
   - 记录：哪个更适合你的使用场景？

## 注意事项

⚠ **Coze 注册后先搭最简单的 Agent**
不要想"我要搭一个完美的 Agent"——今天的目标是从 0 到"能跑起来"，不是从 0 到"好用"。一个只会总结笔记的 Bot 就够了。

⚠ **Prompt 升级不是背公式**
重点是对比"原版 vs 升级版"的效果差异，让你自己感受到差别，而不是记住一个模板。
