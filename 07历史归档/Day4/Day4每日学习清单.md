### 任务 2：3 模型横评——用同一个 prompt 测试 DeepSeek、Kimi、通义千问（40 分钟）

这是本周第 2 个核心产出（横评对比表）。

**横评 prompt（3 个模型都用这个）：**

```
请帮我解释以下 5 个概念，每个概念用：① 一句话定义 ② 一个生活化的比喻 ③ 和其他概念的区别。

概念列表：
1. Agent（智能体）
2. RAG（检索增强生成）
3. Prompt Engineering（提示词工程）
4. Fine-tuning（微调）
5. LLM（大语言模型）

输出格式：每个概念单独一段，段内用 ①②③ 标注。
```

**操作步骤：**
1. 打开 DeepSeek → 粘贴上面的 prompt → 等回复完成 → 截图保存
2. 打开 Kimi → 粘贴同一个 prompt → 等回复完成 → 截图保存
3. 打开通义千问 → 粘贴同一个 prompt → 等回复完成 → 截图保存

**截图命名：**
- `day4_DeepSeek横评.png`
- `day4_Kimi横评.png`
- `day4_通义千问横评.png`

保存到 `作品集素材\week 1\day 4\`

```markdown

> 测试日期：2026-07-28
> 测试 prompt：解释 Agent / RAG / Prompt Engineering / Fine-tuning / LLM 五个概念

## 基础对比

|------|----------|------|----------|
| 回复速度 | ⬜快/中/慢 | ⬜快/中/慢 | ⬜快/中/慢 |
| 解释清晰度 | ⬜ 1-5分 | ⬜ 1-5分 | ⬜ 1-5分 |
| 比喻质量 | ⬜ 1-5分 | ⬜ 1-5分 | ⬜ 1-5分 |
| 概念区分准确度 | ⬜ 1-5分 | ⬜ 1-5分 | ⬜ 1-5分 |

## 细节对比

- DeepSeek 说了什么：（粘贴关键内容）
- Kimi 说了什么：（粘贴关键内容）
- 通义千问说了什么：（粘贴关键内容）
- 我觉得谁说得最好：⬜

### RAG 概念解释

⚠ **关键原则**：横评不是打分比赛，目的是让你在同一主题下对比不同模型的风格差异，从而更深入理解这 5 个概念本身。填表时，哪个模型帮你理解了某个概念，就在那个概念旁边写一句"它让我明白了XX"。

### 任务 4：概念深挖——选 1 个概念深入理解（15 分钟）

⚠ 这是 Day 3 复盘的改进项——"选 1 个概念深入理解（不再只记名字）"

**今天深挖的概念：Agent（智能体）**

理由：Agent 是你的目标岗位核心概念，且目前是 🟡 待验证状态。

操作：
1. 在横评结果的基础上，挑你觉得 Agent 解释得最好的那个模型
2. 追问它：

```
关于 Agent（智能体），我还有几个问题：
1. Agent 和普通聊天机器人有什么本质区别？
2. 一个 Agent 需要哪些核心组件才能工作？

4. 一个人不需要写很多代码，能不能搭建一个有用的 Agent？怎么做？

3. 把追问结果补充到横评表的 Agent 部分
