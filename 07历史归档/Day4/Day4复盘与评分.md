## 二、核心收获

### 收获 1：Agent 从"听过名字"到"能解释清楚"

今天最大的进步是 **Agent 概念从 🟡 推到了 🟢**。能用自己话说清楚：
- Agent = 大脑 + 手脚 + 计划，不只是聊天，还能规划、调用工具、交付结果
- 三个核心组件：规划能力、工具调用、记忆与反馈
- LLM 只能"说"，Agent 能"说"也能"做"

这是目标岗位"智能体搭建师"的核心概念，搞懂它是后面所有学习的前提。

### 收获 2：横评不是比赛，是学习工具

第一次做 3 模型横评，最大的发现不是"谁赢了"，而是：
- **比喻质量比定义更重要**——DeepSeek 定义最完整，但 Kimi 的"全能管家筹备生日派对"让我真正懂了
- **通义千问的主动追问本身就是 Agent 行为的体现**——它不只回答，还想着下一步能帮我做什么
- 横评让我从 3 个角度理解了同一个概念，比只看一个模型的解释更深入

### 收获 3：JD 拆解给了 12 个月的具体方向

3 条 JD 反复出现的 3 个关键词，直接改了我的学习优先级：
- 🔴 P0：Coze / Dify 平台实操（3 条 JD 全要求，入门门槛最低）
- 🔴 P0：Prompt Engineering 深入（已有基础，需要升级）
- 🟡 P1：Python 基础 + RAG 实操
- 🟢 P2：做一个完整的 0→1 项目

行业洞察还告诉我：**71% 的 AI PM 岗位核心是产品基本功 + 行业经验，AI 只是加分项**。所以我最终决胜的不是"懂多少概念"，而是"能做出什么东西"。
