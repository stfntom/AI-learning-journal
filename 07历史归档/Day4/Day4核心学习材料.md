## 一、LLM 和 Agent：两个必须分清的东西

### LLM（大语言模型）

**一句话**：只会"说话/写字"的 AI 大脑。

你已经在用的 DeepSeek、Kimi、ChatGPT、通义千问——它们的底层都是 LLM。你给它一段文字，它预测下一个最可能出现的字，一段一段地生成回答。

**LLM 能做什么**：
- 回答问题、写文章、翻译、总结
- 它只能输出文字，不能替你"做事"

**LLM 不能做什么**：
- 它不能自己去查天气 API 再告诉你结果
- 它不能帮你下单、发邮件、操作软件
- 它没有"手脚"，只有"嘴"

> 比喻：LLM 是一个只会给建议的顾问——你说"我想订机票"，它告诉你怎么订，但不会替你订。

---

### Agent（智能体）

**一句话**：不只会聊天，还能自己规划步骤、调用工具、执行任务并交付结果的 AI 系统。

Agent 的底层也有一个 LLM（负责思考和对话），但 Agent 在 LLM 之外多了三个关键能力：

| Agent 的核心组件 | 说明 | 比喻 |
|---|---|---|
| **规划能力** | 把复杂目标拆成多个步骤，按顺序执行 | 顾问变成项目经理——先列清单再逐项完成 |
| **工具调用** | 能调用外部 API（查天气、搜网页、操作数据库等） | 不只会说，还会动手——拿起温度计测温度而不是猜 |
| **记忆与反馈** | 记住之前做了什么，做完一步后判断是否成功，失败了会调整 | 做完一步回头看一眼，走错路了就拐回来 |

> 比喻：Agent 是一个能帮你办事的私人助理——你说"帮我订周五去上海的机票"，它自己去查日历、比价、下单，最后告诉你结果。

**一句话区分 LLM 和 Agent**：
> LLM 只能"说"，Agent 能"说"也能"做"。LLM 是大脑，Agent 是大脑+手脚+计划。

## 二、横评：今天播客里提到的核心方法

### 什么是横评？

**一句话**：让多个 AI 做同样的任务，对比它们的表现差异。

你今天听的播客就是一次横评：它让 5 个 Agent 平台做同样的任务，然后比较谁完成得更好。

**横评的重点不是"谁赢了"，而是"对比让我看到了什么"**：
- 不同 AI 对同一个概念的解释方式不同 → 你能从多种解释中加深理解
- 有的 AI 比喻好，有的 AI 定义准 → 你能看到同一个概念的不同切面

> 比喻：横评就像让 3 个导游分别带你逛同一个景点——重点不是谁更好，而是你从不同视角看到了更多细节。

---

### 播客里的 5 个 Agent 平台

| 平台 | 播客评价 | 一句话理解 |
|---|---|---|
| **Genspark** | 表现稳定，完成度高 | 大部分任务都能搞定，不挑活 |
| **Flowith Neo** | 分析细致但耗时较长 | 做事很细很慢，像慢工出细活 |
| **Manus** | 表现平均 | 不出彩也不出错，中规中矩 |
| **MiniMax Agent** | 特定任务很强，其他一般 | 偏科生，擅长的科目特别好 |
| **扣子空间**（字节跳动） | 各有擅长，按需选择 | 不同场景用不同方案 |

**播客的核心观点**：
> 评价 Agent，不要看"它用了多强的 LLM"，要看"它最终把任务完成得怎么样"。
> 类比：雇快递员，关键不是他骑什么车，而是包裹有没有准时完好送达。

## 三、横评中提到的其他术语（快速扫一眼）

这些术语在播客和你的概念表里已经出现过，不需要深入，只需要知道"它大概指什么"：

| 术语 | 一句话 | 你现在需要知道的深度 |
|---|---|---|
| **RAG** | 让 AI 先翻资料再回答，像"开卷考试" | 知道它是什么就行，Day 5+ 再深挖 |
| **Prompt Engineering** | 优化你给 AI 的指令，让回答更好 | 你每天都在做，不需要额外学 |
| **Fine-tuning** | 给通用 AI 再喂专业数据，让它变专精 | 知道概念就行，不用急着学操作 |
| **Function Calling / 工具调用** | 让 AI 调用外部接口（查天气、发邮件等） | 这是 Agent 能"动手"的技术基础 |
