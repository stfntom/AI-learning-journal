## 三、周复盘的新执行方式（v4.0 重点）

**问题**：规则有意义，但"用户自己记着做"这个机制失效了。
**解决**：把"提醒和主持"的责任转给 AI。

**执行流程（AI 主动）**：
1. **每次开工第一句**先报："距上次复盘已 N 天 / N 个学习单元"
2. 达到 **7天 或 5个学习单元**（先到为准）→ 在当次任务的**末尾**发起复盘，不打断正事
3. 复盘内容（3问 + 1动）：
   - ① 这段时间**产出了什么**？（必须有可展示物；没有=这段时间没学）
   - ② 哪个概念在实际任务里**被验证/被推翻**了？
   - ③ 下个周期的**最低交付**是什么？（只写1件）
   - ④ **当场更新校准表**（哪个升级、哪个没通过）
4. 用户只需回答，不需要记流程、不需要提案

**给未来 AI 的硬性要求**：用户明确表示"这是效率问题，需要 AI 主动带"。**不主动提醒 = 违反本规则。**

## 四、两项陌生能力的"学成什么样"（用户确认陌生：第4、5项）

### 能力4：需求拆解 + 交付文档

| 项 | 定义 |
|---|---|
| **学成什么样** | 别人给一句模糊需求（例："我们机构想要个帮学生整理错题的东西"），你能产出一份文档，包含：**要解决什么问题 → 打算怎么搭（平台/节点/流程）→ 交付什么 → 怎么判断做成了**。非技术人看完能懂 |
| **怎么练** | **不靠"学"，靠"写3次"**。第一个练习对象=现成的"学习规划私人订制师"（把它写成作品集文档，就是第1次实践） |
| **验收标准** | 拿一个真实场景写出完整方案文档；能被非技术人读懂（找1个人试读，能复述出你要做什么） |
| **优先级** | P5（当前不动），但作品集归档时会顺带练到 |

### 能力5：基础Python

| 项 | 定义 |
|---|---|
| **学成什么样** | 给一个报错脚本，能**看懂在干什么** → **定位到哪一行错** → **改对**。不要求从零写 |
| **最低线** | 能跑通"读本地txt → 调用大模型API → 结果写进新文件" |
| **怎么学** | B站黑马Python前40集（跳面向对象）+ 每学一个语法点让AI出5道题 |
| **验收标准** | 独立跑通上述脚本；遇到报错能自己定位并改对1处 |
| **优先级** | P4——**放在作品集和出题模式之后**（理由见第五节） |

## 五、优先级顺序调整（Day15 建议，用户已接受）

**原顺序**（Day14复盘定）：P0 Dify闭环 → P1 机器人可交付 → P2 出题模式 → P3 作品集1号 → P4 Python → P5 拆解文档

**新顺序调整点**：**把 P3（作品集1号归档）提前到 P2 之前。**

| 新顺序 | 任务 | 提前/调整理由 |
|---|---|---|
| **P0** | Dify闭环收口（"引用考纲列考点"这最后一个问题） | 不动，1–2个单元可完成 |
| **P1** | 机器人可交付（发朋友用 + 3分钟录屏） | 不动 |
| **P2** ⬆️ | **作品集1号归档**（5模块：背景/搭建步骤/迭代记录/演示/价值） | **提前**：它是唯一能提供"即时可见成果"的动作。三次断档全部发生在"连续几天没有可见成果"之后。素材已齐（纯Prompt版 vs RAG版就是现成迭代记录） |
| **P3** ⬇️ | 出题检验模式（第2种模式） | 后移一位，不取消 |
| **P4** | 基础Python | 不动（欠账，但仍排在作品之后） |
| **P5** | 需求拆解+交付文档 | 不动；作品集归档时会自然练到 |
