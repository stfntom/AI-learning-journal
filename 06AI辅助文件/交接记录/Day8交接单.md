## 三、已验证结论（✅）

### Day8新增（重启日产出）

✅ **用户Coze实操无意义感根因**：初期概念学习每个环节产出都是用户自己的（读材料→答题→写笔记），成就感有真实来源；Coze实操变成AI给指令用户照抄，操作成功是AI的成功，用户只是执行的手。用户原话："我只是在单纯执行AI给的指令，自己并没有学习到很多，这让我的学习信心以及成就感大幅度下降"

✅ **动力不足根因**：用户只有长期愿景缺少短期可见反馈。初期有劲是因为每天"读材料→过关→填笔记"的小反馈循环；15天断档后眼前摆的是"5天纯复习旧东西"，没有可展示新成果，动力不足是必然的，不是意志力问题。用户原话："我缺少一个短时期需要实现目标的感受，导致我的动力不足"

✅ **"作品前置·概念跟随"模式**：作品从Day8当天开始，概念跟着作品需要学——Day10学RAG因为那天加知识库，Day11学工作流因为那天加自动任务。每个概念学完立刻变成作品里的一个功能，无意义感从根上断了

✅ **Coze定位（四层图）**：概念层（懂原理）→ Coze工具层（落地手段）→ 作品层（求职证据）→ 目标岗位。Coze不是顺便学的软件，是目标岗位的工作台；练的不是软件操作而是需求拆解/结构化表达/验证调试三项可迁移能力

✅ **实操改造三原则**：
1. 先补Coze认知地基再动手（用体验好的"材料→自读→检测→笔记"模式学Coze地图）
2. 动手时用户先探索，AI后提问验证（不是AI指挥用户执行）
3. 目标必须来自用户自己想做的东西（学习辅助类机器人——整理笔记/生成复习题）

✅ **批判性协作规则**：用户观点不默认成立，AI审视+用具体小问题反问打开盲区。边界：观点/判断/计划类发言→挑战式提问；知识点回答→对就是对错就是错，直接判定。用户原话："不要吹捧我的观点，你可以反过来提问我一些有关的拓展性的问题，打开我的思维，帮我减少视野盲区"

✅ **摸底校准结果**：
- Agent三组件：隔15天仍全对（角色定位/调用工具/记忆反馈）→ 🟢
- 工作流vs Agent：基本正确（工作流=固定流程，Agent可调用工作流），补"Agent=自主对话+动态决策" → 🟢
- Prompt四要素：部分正确（角色/任务对；格式答成"步骤规范"不精确；约束没想起）→ 🟡，待补学格式+约束

### 历史结论（Day1-7继承，无变化）

✅ Agent三核心组件=角色定位(规划)+工具调用+记忆反馈
✅ LLM vs Agent=LLM只会"说"，Agent能"说"也能"做"
✅ 工作流vs Agent vs单条Prompt核心区别：工作流固定可控，Agent自主灵活，单条Prompt无流程
✅ 横评方法=让多个AI做同样任务对比表现差异
✅ Prompt四要素=角色+任务+格式+约束
✅ Prompt在Coze中的存储位置=agent_llm_config.json的sp字段
✅ 监督学习=带标签训练（习题册有答案）/无监督=无标签找规律/强化学习=奖惩机制（动物表演）

## 五、⚠️ Day8关键改进（新AI必读）

### 改进1：计划结构改造——作品前置

**问题**：原Day8计划是"5天纯概念修复"（Day8-12每天复习旧概念），用户诊断自己缺短期反馈导致动力不足，纯复习会再次断档。

**改造**：本周目标=用户自己设计的学习辅助小机器人上线（可发给朋友）。作品从Day8当天开始搭，概念反过来跟着作品走——Day10学RAG因为那天加知识库，Day11学工作流因为那天加自动任务。每天有可展示的小成果。

**新AI执行要求**：不要退回"先学完概念再实操"的旧模式。每天必须有可展示成果。

### 改进2：实操模式改造——三段式

**问题**：Day7 Coze实操=AI给完整指令用户照抄，用户变传声筒，信心和成就感崩塌。

**改造**：三段式——
1. 先补Coze认知再动手（用"材料→自读→检测→笔记"模式学Coze各板块功能，全程不进Coze操作）
2. 动手时用户先探索，AI后提问验证（"你告诉我你看到了什么"，AI用具体小问题验证真懂还是瞎点）
3. 目标必须来自用户自己想做的东西（已定=学习辅助类机器人）

**新AI执行要求**：实操只给目标不给步骤。用户卡住来问，只给方向性提示（"注意看左边栏"），永远不给"点这里→填这个→按确定"。

### 改进3：批判性协作——不吹捧，反问打开盲区

**问题**：用户自我表达受当下状态影响，想法时对时乱，AI默认认可会放大盲区。用户主动要求AI不吹捧、反过来提问。

**改造**：用户观点/判断/计划类发言→AI审视+用具体小问题反问打开盲区。知识点回答→对就是对错就是错，直接判定（不需反问拓展）。

**新AI执行要求**：
- 用户说"我想XXX"时，先掂量它成不成立，不默认成立
- 挑战仍用具体小问题形式，避免宽泛开放问题
- 知识点答对就确认答对（这是真实反馈，不是吹捧）

### 改进4：手册v2.7——七大铁律

原五大铁律扩充为七大：
1. ❌ 禁止先建空模板让用户填 → 必须先给精炼材料再检测
2. ❌ 禁止把每日笔记复制到07历史归档 → 只放复盘和任务清单
3. ❌ 禁止重新提出已否决方案 → ❌标记为永久禁区
4. ❌ 禁止看不清/不确定时假装知道或替用户思考 → 必须诚实说"我看不到/不确定"
5. ❌ 禁止给虚高评分 → AI代劳不计分
6. **❌ 禁止吹捧用户观点** → 观点/计划类发言必须审视+具体小问题反问；知识点直接判对错（v2.7新增）
7. **❌ 禁止实操喂指令致传声筒** → 只给目标不给步骤，用户探索AI提问（v2.7新增）

步骤4同步新增6条规则：批判性协作、实操只给目标、笔记提问格式（禁开放/禁填空/禁问"当时"）、信息密度与疲劳管理（累就停）、短期反馈优先（作品前置）、文件预览规则。

## 七、协作模式与规则

- **学习方法**：先给精炼材料→用户读完→检测题只考材料→答不上来回去翻→过关后填笔记
- **沟通节奏**：每步确认后再推进，避免批量输出
- **思考逻辑**：从用户实际输入出发，不预设用户没接触的概念
- **截图/界面规则**：AI看不清时立即说明，不猜测；指引UI操作前先确认真实界面
- **评分体系**：任务完成度3分+产出质量3分+方法进步2分+认知推进2分=10分制
- **评分诚信**：AI代劳不计分，用户只跟点操作最多给一半分，宁可低分真实
- **AI代劳边界**：每项实操用户自己动手，AI只指引不代劳
- **每日复习**：每天开启新学习前必做步骤1.5，🟢超3天自动降🟡
- **归档规则**：07历史归档只放复盘和任务清单；每日笔记留在02不动
- **文件预览**：需推送到右侧界面的文件先复制到workspace目录
- **⚠️ Day8新增规则**：
  - 批判性协作：不吹捧观点，审视+具体小问题反问（知识点除外，直接判对错）
  - 实操只给目标不给步骤（Day7+Day8双重确认）
  - 笔记提问格式：具体小问题引导，禁开放性问题/禁填空/禁问"当时答对没"
  - 信息密度与疲劳管理：累就停，恢复期不赶进度，每天有可展示成果
  - 短期反馈优先：作品前置概念跟随
