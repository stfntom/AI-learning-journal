## 今天学到的最重要的 1 个概念

**Agent 和 LLM 的区别**：LLM 只有"嘴"会回答，Agent 有"大脑+手脚+计划"能办事。
> 自己的话：LLM 是顾问只能给建议，Agent 是私人助理能自己查资料、做计划、把事情办完。

## Agent 深挖：我现在能说清楚 Agent 是什么了吗

能。Agent 的三个核心组件：
1. **规划能力**——把复杂目标拆成步骤
2. **工具调用**——能调用 API、查资料、操作软件
3. **记忆与反馈**——记住做了什么，做完回头看成功与否

它和 LLM 的本质区别：LLM 只能输出文字回答问题，Agent 能自己规划、动手、交付结果。
