### JD 1：Coze 智能体搭建师 @ 星链智汇（长春）

**薪资范围**：1-2万/月

**必须具备的能力**：
1. **精通 Coze（扣子）平台**——能独立完成对话智能体、RAG 智能体、工作流智能体的搭建
2. **Prompt Engineering**——能优化提示词，让智能体输出准确高效
3. **编程能力**——至少掌握 Python 或 JavaScript 之一，能写脚本解决问题
4. **API 与数据处理**——熟悉 RESTful API 调用、JSON 数据格式、SQL 基础
5. **需求转化能力**——能把业务需求翻译成可落地的技术方案

**加分项**：
- 有扣子平台搭建经验（或 Dify、FastGPT 等类似低代码平台）
- RAG 实践经验（知识库构建、文档解析、向量检索）
- 沟通表达好，能为客户提供培训和技术支持

**我目前还缺什么**：
- ❌ 没用过 Coze 平台（今天刚在播客里听到"扣子空间"这个名字）
- ❌ Python/JavaScript 编程能力为零
- ❌ 不懂 API 调用和 SQL
- ✅ Prompt Engineering 我每天都在做（用 DeepSeek/Kimi 写指令就是在做提示词工程）
- ❌ 需求转化能力没经过验证（没做过完整项目）

## 总结：这 3 条 JD 共同要求的核心能力是什么？

反复出现的 **3 个能力关键词**：

1. **💡 Prompt / 工作流设计能力**——3 条 JD 都要求能设计智能体的提示词和工作流逻辑，这是搭建师和产品经理的"入场门票"
2. **💡 RAG / 知识库实操**——3 条 JD 全部提到 RAG（检索增强生成）或知识库构建，这是智能体能"干活"的技术基础
3. **💡 需求转化 + 落地交付**——不管是搭建师还是产品经理，核心不是"懂多少概念"，而是能把需求变成可运行的产品并交付上线
